lights-out-line writes one status update line to a text file: the line an agent posts the moment its human shuts the laptop. The line was picked from 39 candidates by pairwise judging against the brief — a real status line in the agent's own voice, its sadness carried by one small exact detail of a machine's life instead of announced grief.

The line:

> The cursor has blinked 4,800 times since she left. I counted.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 61 characters, a single line, and ends on its strongest beat. The program builds the line from two beats — the counted fact, then the turn that closes it — and checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
